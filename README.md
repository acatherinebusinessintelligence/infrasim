# InfraSim

Simulador formativo de Gestión de Infraestructura TI.

Ingresa con tu correo, sortea un caso, responde 10 preguntas y revisa tu progreso de aprendizaje. El acceso identifica el progreso dentro del simulador; no reemplaza un sistema institucional de autenticación.

El resultado es un indicador de aprendizaje y no corresponde a una nota oficial.

Sitio: https://acatherinebusinessintelligence.github.io/infrasim/
